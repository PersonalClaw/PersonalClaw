One subagent's result is injected back automatically as a `[Subagent completion event]` message — don't poll, just wait. Two or more tasks in a `tasks` array run as one batch run, each task an object with its `task`, `objective`, `output_format` and `boundary`; a batch's results are not sent back, so wait for it with `workflow_observe` and read each branch with `workflow_status`, on the run id it returns. Tell the user what you started, then synthesize the results into your final answer. Do NOT start doing the work yourself after spawning — that wastes the subagents. If a task is small enough to do in one step, don't spawn at all.
