Attribution (optional, on the `semantic` items above): when a fact is only true because SOMEONE SAID IT, key it `claim.*` and add `"holder"` plus `"weight"` instead of asserting it as fact. `holder` is one of `user` (the user stated it), `assistant` (your own synthesis), `person:<entity_id>` (a named third party from the entity graph), or `external` (second-hand / an outside source). `weight` is 0.0-1.0 in 0.05 steps — how strongly the claim is held, NOT how likely it is true. Second-hand claims are capped lower automatically, so do not inflate them. Use this sparingly: a fact the user simply stated about the world stays a plain `pref.*`/`project.*`/`user.*` item with no holder. "Alex thinks the migration will slip" is `{"key": "claim.migration_slip", "value": "the migration will slip", "holder": "external", "weight": 0.4}`; "the migration slipped" is a plain fact.
