# UX evidence

Screenshot evidence for UI/UX pull requests, produced by the `personalclaw-ux`
skill. **This branch is never merged.** It exists only to host images that PR
comments reference by raw URL, so that PR diffs stay free of binary churn.

Each cycle adds `<cycle>/<before|after>/<surface>.png`. References are pinned to
the commit SHA, never to this branch ref, so reviewed comments keep showing the
images they were written against.
