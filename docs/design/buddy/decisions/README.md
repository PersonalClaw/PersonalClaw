# Buddy decisions

The buddy's decisions that rest on evidence, one file each, with that evidence beside it: the rig,
chosen by a measured spike, with its numbers and the candidates that lost (`rig.md`, [#3887]); and
the originality record, which compares the buddy's layouts, motion and sounds side by side and ends
with the maintainer's dated sign-off (`originality.md`, [#4570]).
