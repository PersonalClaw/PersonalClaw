# Buddy decisions

The buddy's decisions that rest on evidence, one file each, with that evidence beside it: the rig,
chosen by a measured spike, with its numbers and the candidates that lost ([`rig.md`](rig.md),
[#3887]), measured by [`rig-measure.mjs`](rig-measure.mjs) and its scratch window
[`rig-window.cjs`](rig-window.cjs), each run's raw numbers in `rig-runs/`, the spike's first
runs, from before the buddy's frame rate, in `rig-runs/spike/`, and the re-measure on a quiet
machine in `rig-runs/quiet/` (120 Hz) and `rig-runs/quiet-60hz/`; and the originality record, which
compares the buddy's layouts, motion and sounds side by side and ends with the maintainer's dated
sign-off (`originality.md`, [#4570]).
